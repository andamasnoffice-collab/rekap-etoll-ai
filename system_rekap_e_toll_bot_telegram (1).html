Cara Kerja Integrasi Bot Telegram

  1. Pengguna mengambil foto struk pembelian/top-up e-toll menggunakan kamera ponsel.
  2. Kirim foto tersebut ke @ETollRecapBot di Telegram.
  3. Webhook bot mengirim gambar ke Gemini Vision OCR AI.
  4. AI mengekstrak: Nomor Kartu, Nominal, Tanggal, dan Merchant secara presisi.
  5. Data langsung tercatat otomatis ke dalam database rekap bulanan tanpa perlu input manual!
bot_server.py (Code Backend Telegram) Python + Gemini API 
import os
from telegram import Update
from telegram.ext import Application, MessageHandler, filters, ContextTypes
import google.generativeai as genai

genai.configure(api_key=os.environ["GEMINI_API_KEY"])
model = genai.GenerativeModel('gemini-3-flash-preview')

async def handle_photo(update: Update, context: ContextTypes.DEFAULT_TYPE):
    # 1. Download photo dari Telegram
    photo_file = await update.message.photo[-1].get_file()
    image_bytes = await photo_file.download_as_bytearray()
    
    # 2. Kirim ke Gemini AI Vision OCR
    prompt = "Ekstrak JSON: {cardNumber, nominal, date, cardType, merchant}"
    response = model.generate_content([
        {"mime_type": "image/jpeg", "data": bytes(image_bytes)},
        prompt
    ])
    
    # 3. Simpan ke database Rekap Bulanan
    data = response.text
    
    await update.message.reply_text(f"✅ Struk berhasil dicatat!\n{data}")

app = Application.builder().token("YOUR_TELEGRAM_BOT_TOKEN").build()
app.add_handler(MessageHandler(filters.PHOTO, handle_photo))
app.run_polling()
